The user (2026-07-15, during the B4 investigation): "Please use simple and
direct language. State what is fact and why it matters. You mask meaning with
the way you talk." Earlier same session: "you use overcomplicated language for
simple ideas, and I think this only serves to confuse you" and "you speak
confidently and in flowery language but never actually understand."

**Why:** Ornate phrasing hides weak reasoning (from the user AND from me), and
makes real findings hard to pick out. The user reads results, not prose.

**How to apply:** Short sentences. One fact per sentence. "X happened. It
matters because Y." No metaphors ("bracket the mystery", "crack the case"),
no headline adjectives ("decisive", "damning", "gold"), no narrative arcs.
When uncertain, say "I don't know" plainly. Numbers with error bars, claims
tagged fact vs guess. Related: [[implementation-runbook]].
